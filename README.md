# GitHub Actions

Reusable GitHub Actions workflows and Composite Actions for the Engineering Lab ecosystem.

## Overview

This repository provides reusable automation that promotes consistency, standardization and best practices across Engineering Lab repositories.

Automation published by this repository is versioned and intended to be consumed through GitHub Releases.
